# Mise en ligne

Activer GitHub Pages avec la source GitHub Actions, puis pousser sur la branche main. Le workflow publie dist après les vérifications. Le déploiement refuse de démarrer si le fichier LICENSE est absent.

Cette copie ne contient pas l'historique de développement ni les médias de référence. La simulation est identique ; le deux-tons est identique à celui du site et les documents officiels sont consultables par leurs liens.
